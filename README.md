# 🧵 Tejido Social

> *Un tejido se forma hilo a hilo. Un movimiento, persona a persona.*

**Tejido Social** es un framework de código abierto para la organización comunitaria decentralizada.

## 🚀 Inicio Rápido

👉 **[Visita https://tejidosocialcr.netlify.app/](https://https://tejidosocialcr.netlify.app/)** para acceder a la documentación completa.

---

## 📁 Estructura del Repositorio

Este es un monorepo que contiene:

- **`tejido-social-web/`** — Sitio web Docusaurus con toda la documentación de Tejido Social
  - Guías prácticas (cómo organizar protestas, seguridad, etc.)
  - Estructura de roles y niveles de participación (observador → formador)
  - Organismos de trabajo autónomos (acción callejera, medios, educación, etc.)
  - Recursos reutilizables (cánticos, plantillas, FAQ, glosario)
  - Explicaciones conceptuales (economía solidaria, historia, principios)
