# 🧵 Tejido Social

> *Un tejido se forma hilo a hilo. Un movimiento, persona a persona.*

**Tejido Social** es un framework de código abierto para la organización comunitaria decentralizada. Provee una estructura de conocimiento, roles y herramientas para que cualquier comunidad pueda movilizarse de manera efectiva, autónoma y sostenible — sin reinventar la rueda.

Este repositorio no pertenece a ningún movimiento específico. Es una plataforma neutral que puede ser adoptada, adaptada y bifurcada por cualquier causa o comunidad.

---

## 🎯 ¿Para qué sirve esto?

La mayoría de los movimientos sociales enfrentan los mismos problemas:

- Gente nueva llega con energía o indignada pero no sabe qué hacer
- El conocimiento vive en la cabeza de pocas personas
- No hay estructura clara de roles o progresión, se desmotivan
- Los esfuerzos están fragmentados y no se coordinan
- El agotamiento destruye a los organizadores más comprometidos

**Tejido Social** resuelve esto documentando un sistema completo: desde cómo ser un observador en tu primera protesta, hasta cómo construir economías alternativas en tu comunidad.

## 🌱 El Camino de Participación

Tejido Social propone una progresión natural de compromiso. No hay jerarquía — hay profundidad:

| Nivel | Rol | Compromiso |
|-------|-----|------------|
| 0 | **Observador** | Asistir, aprender, no hacer daño |
| 1 | **Participante** | Protestar con conocimiento básico |
| 2 | **Miembro Activo** | Contribuir en un organismo específico |
| 3 | **Coordinador** | Facilitar y sostener un organismo |
| 4 | **Formador** | Entrenar a otros, multiplicar el movimiento |

Cada nivel tiene expectativas claras, recursos específicos y un camino hacia el siguiente nivel.

---

## 🔧 Los Organismos

Un **organismo** es un grupo de trabajo autónomo. Funciona de manera independiente pero coordinada con el resto del movimiento.

Cada organismo tiene:
- Un propósito claro
- Actividades concretas
- Recursos y herramientas
- Cómo unirse
- Cómo coordinarse con otros organismos

**La clave:** No necesitás permiso para actuar dentro de tu organismo. Solo seguís los principios del movimiento.

---

## 🤝 Modelo de Autonomía

Tejido Social opera bajo un principio central:

> **Cualquier persona puede organizar una acción, en cualquier lugar, en cualquier momento — siempre que siga los principios documentados.**

Esto significa:
- No hay un centro que aprueba cada acción
- No hay una única organización que controla el movimiento
- Hay un marco compartido que asegura coherencia y coherencia ética
- El conocimiento es de todos

Este modelo está inspirado en organizaciones como **BDS** (Boycott, Divestment, Sanctions), **Extinction Rebellion**, y el **Movimiento Sunrise**.

## 🚀 Cómo Usar Este Repositorio

### Para individuos:
1. Lee `docs/intro.md`
2. Identifica tu nivel actual en `docs/niveles/`
3. Elige un organismo en `docs/organismos/`
4. Usa las guías en `docs/guias/` para tu próxima acción

### Para grupos o comunidades:
1. Haz un fork de este repositorio
2. Adapta el contenido a tu causa y contexto
3. Agrega tus propios recursos locales
4. Comparte con tu comunidad

### Para contribuir:
1. Fork → Branch → Pull Request
2. Lee `CONTRIBUTING.md` antes de contribuir
3. Todo el contenido debe ser en español (por ahora)
4. Sé respetuoso, claro y práctico

## 🌍 ¿Quién puede usar esto?

Cualquier movimiento o comunidad que:
- Quiera organizarse de manera horizontal y decentralizada
- Necesite documentar su conocimiento para escalar
- Busque un punto de entrada claro para nuevas personas
- Quiera construir comunidad, no solo protestar
