# Recursos

Material de consulta rápida para el trabajo del comité distrital, y algún recurso independiente de utilidad general.

- **[Glosario](./glosario.md)** — términos y siglas usados en la organización distrital del Frente Amplio.
- **[Preguntas Frecuentes](./preguntas-frecuentes.md)** — dudas comunes sobre la participación en el comité.
- **[Plantilla de Minuta](./plantilla-minuta.md)** — plantilla base para que la Secretaría registre las reuniones del comité.
- **[Modelo de Acuerdo Constitutivo](./acuerdo-constitutivo-modelo.md)** — plantilla orientativa para el acuerdo con el que una asamblea se constituye formalmente como comité.
- **[Cómo Presentar un Recurso de Amparo](./presentar-recurso-de-amparo.md)** — recurso independiente, no del partido: cómo saber si te corresponde, qué reunir para el escrito y cómo se presenta ante la Sala Constitucional. Sin revisión legal todavía.
